# DevNeganSmith - Disable Native Radio

Recurso ligero para FiveM creado por **DevNeganSmith** que desactiva la radio nativa de GTA V dentro de los vehículos.

## ¿Para qué sirve?

- Apaga automáticamente la radio de los vehículos.
- Bloquea los controles nativos para cambiar emisoras.
- Evita que la radio de GTA interfiera con sistemas de música personalizados.
- No requiere QBCore, ESX ni Qbox para funcionar.

## Instalación rápida

1. Copia `devnegansmith_disable_native_radio` dentro de tu carpeta `resources`.
2. Agrega en `server.cfg`:

```cfg
ensure devnegansmith_disable_native_radio
```

3. Reinicia el recurso o el servidor.

**Autor:** DevNeganSmith  
**Versión:** 1.0.0  
**Compatibilidad:** FiveM / Qbox / QBX / QBCore / ESX / Standalone
